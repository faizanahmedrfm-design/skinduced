# SkinDuced Luxury Aesthetic Clinic Website

A premium, responsive Next.js 15 website concept for **SkinDuced**, built for a high-end skin and aesthetic clinic experience.

## Stack

- Next.js 15 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- GSAP + ScrollTrigger
- Lucide React icons

## Included pages

- Home
- About SkinDuced
- Treatments
- Before & After Results
- Pricing
- Testimonials
- Blog
- Contact Us
- Book Consultation

## Premium features

- Full-screen cinematic hero
- Animated luxury navigation
- Framer Motion reveal animations
- Route transition wrapper
- GSAP scroll-triggered luxury background elements
- Mouse-following glow effect
- Elegant loading screen
- Featured treatment cards
- Interactive treatment gallery
- Before and after image comparison sliders
- Animated counters
- Testimonial carousel
- FAQ accordion
- Mobile-first consultation booking form
- SEO metadata, sitemap, and robots file
- Accessibility-conscious labels, semantic sections, and reduced motion support

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

## Notes before launch

1. Replace placeholder Unsplash images with approved SkinDuced clinic, room, treatment, and patient imagery.
2. Replace placeholder pricing with final clinic-approved pricing.
3. Connect the booking form to your CRM, email service, or appointment system.
4. Review all aesthetic treatment wording for Australian advertising and health practitioner compliance before publishing.
5. Add real testimonials only with permission and approval.
6. Add treatment-specific disclaimers where required, especially for before and after imagery.
